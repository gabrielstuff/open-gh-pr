# Open GH PR

Raycast extension: type `#NUMBER` to open a pull request from any of your repos.

- Connect once with GitHub device login, no token to paste.
- Opening it lists the PRs you are involved in, across all repos, in one request.
- `#123` checks PR 123 in your starred repos (or your 10 most recently pushed) in one GraphQL request. `repo#123` and `owner/repo#123` target one repo.
- Star repos with **Choose Searched Repositories** (or ⌘⇧S).

```sh
npm install && npm run dev
```
